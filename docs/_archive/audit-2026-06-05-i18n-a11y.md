## 4. i18n behavior checks

| Check | Result | Detail |
|---|---|---|
| Switcher injected on all 9 pages | **8/9** | `404.html` has no `.site-nav` → `buildSwitcher()` returns early. No way to switch language from the 404. |
| `localStorage["al-lang"]` persists | ✓ | Try/catch around private-mode throw. |
| `<html lang>` + `<html dir>` flip together at document level | ✓ | `setHtmlAttrs()` writes to `documentElement` (correct for SR voice selection). |
| Pre-paint flash prevented | ✓ | `init()` calls `setHtmlAttrs(lang)` before `translate(lang)`. |
| Meta tag swap (title / description / OG / Twitter) | **2/9** | Works on `home` + `visa` only. Voyages + 5 trip pages + 404 stay French in `<title>` / OG / Twitter when user switches to EN/AR — the 12 `meta.*` dict entries for those pages are present but never reached. |
| AR font lazy-load | ✓ | Cairo + Tajawal added on first AR selection. |
| AR digit isolation | **Partial** | `styles.css:9920–9952` covers 23 selectors (`.value-card__num`, `[data-counter]`, `.price`, `.phone-card__num`, `.stat-card__num`, `.hero__price strong`, prices, breakdowns, etc.) with `direction:ltr; unicode-bidi:isolate`. **Missing:** inline `<strong>1 200+</strong>` inside AR `agency.p2_html` HTML — no `<span class="num-ltr">` wrap. |
| Currency formatting | hardcoded per dict | FR "190.000 DA", EN "DZD 190,000", AR "190.000 د.ج"/dinar — 3 conventions, no central formatter. Spaces are regular (not non-breaking). |
| Date strings | hardcoded | "12, 19, 26 Juin" / "Mars–Mai 2026" / "Jour 1" — no `Intl.DateTimeFormat`. |

## 5. RTL & AR layout (`styles.css:9893–9975`)

Present: AR font stack under `:root[lang="ar"]`, h-weight bump (600), `em→not italic`, 23-selector digit isolation, 5 RTL adjustments (arrow flip, ribbon position, nav-logo letter-spacing, nav-links padding, FAB anchoring).

## 9. AR translation quality (spot-check)

20-string sample reads as natural MSA, consistent register, with appropriate Algerian-context proper nouns (بُرج بوعريريج, المسيلة, قسنطينة, أليانس ترافل). `hero.title_em` ("مرتَّبٌ من أوّله إلى آخره") is idiomatic. `visa.faq` answers are formal but readable. AR uses Western digits (`1.200`) throughout — Algerian convention; consistent. EN strings scan as natural British English ("travellers", "Algiers"), "wilaya" preserved as a loan-word; no obvious French calques.
