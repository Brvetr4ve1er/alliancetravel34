Engineering you don't have to think about

We sweat the details
so your booking team doesn't have to.

Every choice below is documented in /docs — design system, color tokens, image manifest, sitemap, roadmap.

Slow site on Algerian 4G
Hand-written HTML/CSS, no framework, no bundler. WebP-first with image-set() + mobile crops. Font subset, service-worker offline cache.
"Looks generic, looks like every other agency"
Per-trip accent themed via one data-region attribute on <body>. Caspian teal, Red Sea aqua, Bosphorus blue — same skeleton, five moods.
Conversion drop on mobile
Sticky-total bar on scroll. Floating WhatsApp FAB. Keyboard-accessible lightbox. Dark mode toggle that persists in localStorage.
SEO invisible
Open Graph + Twitter cards + 6 trip-specific OG images. schema.org/TravelAgency + schema.org/TouristTrip JSON-LD on every trip page.
Accessibility audit risk
Skip-link, semantic landmarks, ARIA labels, focus management. Color contrast WCAG-verified in COLOR-MAP.md.
Deploy headaches
One folder. Any static host (Netlify · Vercel · Cloudflare Pages · S3). HTTPS auto-detected for the SW. Cache headers documented.
